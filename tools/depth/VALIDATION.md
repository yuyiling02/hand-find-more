# 第一版验证记录

环境为 Unity 6000.6.5f1、RTX 4060 Laptop GPU、独立 Python 3.11。

已验证

- Unity 批处理 C# 编译通过。
- Python 脚本语法检查通过。
- 4 项测试通过，覆盖 TCP 分包读取、断连、手掌内部采样和退化区域拒绝。
- 官方源码固定提交、Small 权重下载及 SHA256 校验完成。
- 项目虚拟环境已安装 `torch 2.5.1+cu124` 与 `torchvision 0.20.1+cu124`，CUDA 12.4 识别 RTX 4060 Laptop GPU。官方下载域名握手失败后，使用 PyTorch S3 入口和 uv 硬链接安装。
- CUDA 推理服务通过本地 TCP 测试。服务加载并预热模型后，640×480 测试图像请求收到有效相对深度，服务报告单次推理及采样耗时约 55 ms。

待验收

- 校准端点、左右手切换、过期数据、重启与恢复的运行时测试。
- RGB 方向与关键点叠合的真实摄像头核对。
- 五分钟频率、帧率、延迟统计。
- 静止、伸收、握拳翻掌、背景干扰和各视角杯子／微波炉操作。

用户实测伸手／收手的前后控制效果弱于画面上下映射。增加灵敏度后仍未达到预期，当前默认使用原有控制。F1 面板可手动开启实验深度模式。
